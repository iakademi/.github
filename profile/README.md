## Hakkımızda

[İ-Akademi](https://iakademi.com), İzmir merkezli bir BT eğitim merkezidir. Microsoft, Office ve Power Platform'dan Cisco ağ teknolojilerine, siber güvenlikten yazılım geliştirmeye, PMP/Scrum/Agile'dan Windows Server ve Active Directory'ye uzanan geniş bir yelpazede eğitimler sunar. Aynı zamanda **Microsoft Eğitim Partneri**dir.

Bu organizasyonda, eğitimlerimizde kullanılan örnek kodlar, lab rehberleri, şablonlar ve kaynak materyaller açık olarak paylaşılır.

## Eğitim Alanlarımız

- **Microsoft, Office ve Power Platform:** Excel, Power BI, Power Automate ve daha fazlası (Microsoft Eğitim Partneri)
- **Cisco:** CCNA ve ağ teknolojileri
- **Siber güvenlik:** Savunma odaklı eğitimler
- **Yazılım:** C#/.NET, Python, SQL Server, web geliştirme
- **Proje yönetimi:** PMP, Scrum, Agile
- **Sistem yönetimi:** Windows Server, Active Directory
